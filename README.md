# Каталог фильмов

Современное адаптивное веб-приложение для каталога фильмов, построенное на Angular 21 и Nx. Просматривайте и ищите фильмы в коллекции с детальной информацией, отображаемой в элегантном модальном окне.

## 🎬 Функции

- **Сетка фильмов**: Красивая карточная компоновка с постерами, названиями и годами выпуска
- **Поиск в реальном времени**: Поиск фильмов по названию с мгновенной фильтрацией
- **Модальное окно с деталями**: Клик по карточке фильма открывает детальную информацию:
  - Название фильма и год выпуска
  - Теги жанров
  - Полное описание
  - Рейтинг
  - Постер фильма
- **Адаптивный дизайн**: Полностью адаптивная верстка, оптимизированная для мобильных устройств, планшетов и десктопов
- **Современный UI/UX**: Чистый, минималистичный дизайн с плавными анимациями и переходами
- **Доступность**: ARIA-атрибуты, навигация с клавиатуры (Escape для закрытия модального окна) и управление фокусом

## 🛠️ Технологический стек

- **Фреймворк**: Angular 21
- **Инструмент сборки**: Nx 22.3.3
- **Язык**: TypeScript 5.9
- **Стилизация**: SCSS с методологией БЭМ
- **Управление состоянием**: Angular Signals
- **HTTP клиент**: Angular HttpClient
- **Тестирование**: Vitest

## 🚀 Начало работы

### Требования

- Node.js (v18 или выше)
- npm (v10.8.2 или выше)

### Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd movie-catalog
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите сервер разработки:
```bash
npm start
```

Приложение будет доступно по адресу `http://localhost:4200`

### Сборка для продакшена

```bash
npm run build
```

Продакшен сборка будет сгенерирована в `dist/movie-catalog/browser/`

### Запуск тестов

```bash
npm test
```

## 📝 Доступные скрипты

- `npm start` - Запустить сервер разработки
- `npm run build` - Собрать для продакшена
- `npm run watch` - Сборка в режиме наблюдения для разработки
- `npm test` - Запустить unit тесты

## 🎨 Особенности дизайна

### Адаптивные брейкпоинты

- **Мобильные**: < 500px - Вертикальная компоновка карточек, модальное окно снизу
- **Планшеты**: 500px - 767px - Оптимизированная сетка и модальное окно
- **Десктопы**: 768px+ - Полная горизонтальная компоновка с большими модальными окнами
- **Большие экраны**: 1200px+ - Улучшенные отступы и типографика

### Методология БЭМ

Все CSS классы следуют методологии БЭМ (Block Element Modifier):
- Блоки: `.movie-card`, `.movie-detail-modal`, `.header`
- Элементы: `.movie-card__title`, `.movie-detail-modal__content`
- Модификаторы в настоящее время не используются

## 🌐 Деплой

### Vercel

Проект настроен для деплоя на Vercel с помощью `vercel.json`:

```json
{
  "buildCommand": "npm run build",
  "outputDirectory": "dist/movie-catalog/browser"
}
```

Для деплоя:

1. Подключите ваш репозиторий к Vercel
2. Vercel автоматически обнаружит конфигурацию
3. Приложение будет задеплоено и доступно по вашему Vercel URL

JSON файл с данными (`movies.json`) автоматически включается в сборку и будет доступен по адресу `/assets/data/movies.json`.

## 📊 Структура данных

Фильмы хранятся в `src/assets/data/movies.json` со следующей структурой:

```typescript
interface Movie {
  title: string;
  year: number;
  poster: string;
  genres: string[];
  description: string;
  rating: number;
}
```

## 🎯 Реализация ключевых функций

### Функциональность поиска

- Фильтрация в реальном времени при вводе
- Поиск без учета регистра
- Сообщение о пустом состоянии, когда результатов не найдено
- Использует Angular Signals для реактивного управления состоянием

### Компонент модального окна

- Открывается при клике на карточку фильма
- Закрывается при клике на фон, нажатии Escape или кнопки закрытия
- Блокирует прокрутку body при открытии
- Плавные анимации и переходы
- Полностью доступен с ARIA-атрибутами

### Адаптивное модальное окно

- **Мобильные**: Стиль bottom sheet, полная ширина
- **Планшеты/Десктопы**: Центрированное модальное окно с горизонтальной компоновкой
- **Альбомная ориентация**: Оптимизированная компоновка для альбомной ориентации
